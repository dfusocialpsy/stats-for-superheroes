Warum brauchen wir Objekte?

Warum brauchen wir Objekte?

  • R ist eine objektbasierte Sprache
    → wir arbeiten die meiste Zeit mit Objekten
  • Objekte beinhalten („speichern”) Informationen (Elemente)
    → Information wird wiederverwertbar
  • Objekte können jederzeit entfernt werden: rm(objekt)

Achtung!

Vergeben Sie niemals Objektnamen, die ident mit Funktionen sind, wie mean <- my_object

Erstellen eines Objekts

Hierfür nutzen wir den “Assign-Operator” <-

objekt_01 <- c(2, 4, 8)
objekt_01
[1] 2 4 8


Das Objekt erscheint im Environment-Fenster (RStudio) und kann aufgerufen werden.
Shortcut: “Option/Alt” + “-”

Welche Objekttypen gibt es?

Scalar

  • Scalar ist die einfachste Objektart
  • besteht aus einem einzelnen Element
  • Werte können alles Mögliche sein (z.B. Zahl, Buchstabe, Ergebnis …)
# Examples for numeric scalars
a <- 7
b <- 9 * 12
c <- (a + b) / 4

Scalar

Nuten Sie für Text (character) immer Anführungszeichen!

Scalar

  • numeric und character Scalars werden unterschiedlich behandelt
  • mathematische Operationen machen nur bei numeric Sinn!
# Numbers
a_n <- 1
b_n <- 2

a_n + b_n
[1] 3


# Characters
a_c <- "1"
b_c <- "2"

a_c + b_c
Error in `a_c + b_c`:
! non-numeric argument to binary operator

Vector

  • Vektoren sind kombinierte Scalars
  • bestehen aus mehreren Elementen
    z.B. die Zahlen von 1 bis 10
  • können nur Elemente eines Typs enthalten
  • bei unterschiedlichen Typen kommt es zur „Zwangstransformation”

Exkurs: Vector types

Typ Bedeutung
double alle Zahlen
integer Zahlen ohne Dezimalstellen
character Text
logical TRUE vs. FALSE
complex komplexe Zahlen
raw Raw Bytes von Daten

Holy Matrices

Wie verbinde ich Vektoren zu einer Matrix?

Funktion Beschreibung Beispiel
cbind(a, b, c) Überträgt Vektoren als Spalten in eine Matrix cbind(1:5, 6:10, 11:15)
rbind(a, b, c) Überträgt Vektoren als Zeilen in eine Matrix rbind(1:5, 6:10, 11:15)

Wie erstelle ich Matrices und Dataframes

Funktion Beschreibung Beispiel
matrix(x, nrow,ncol, byrow) Erstellt eine Matrix basierend auf Vektor x matrix(x = 1:12, nrow = 3, ncol = 4)
data.frame() Erstellt einen Dataframe. Die Spaltennamen werden definiert. data.frame("age" = c(20, 24), "sex" = c("m", "w"), "pkt" = c(55, 60))

Wie wähle ich ein Element aus?

Wie finde ich den Ganoven?

  • Einzelne Elemente innerhalb eines Vektors werden mit [ ] indiziert
  • z.B. möchte ich das 66. Element eines Vekotrs wissen
  • Teildatensätze erstellen
# Ermöglicht eine Reproduktion
set.seed(123)   
# Erstellen eines Vectors
vec_ft <- sample(
    x = 1:1000,
    size = 100,
    replace = FALSE
)
# Wert des 66. Elements
vec_ft[66]
[1] 277

Wie wähle ich mehrere Elemente aus?

  • Es können auch mehrere Elemente mittels [ ] indiziert werden
  • z.B. möchte ich das 11. und 22. Objekt eines Vektors
vec_ft[c(11, 22)]
[1] 244 649

Muss ich immer alles Tippen?

  • Es können auch mehrere Elemente mittels [ ] indiziert werden
  • Es können auch Objekte zum Indizieren genutzt werden
# Werte des 11., 22., 33. und 44. Elemets

# Erstellen eines "Auswahlobjektes"
el_to_ff <- c(11, 22, 33, 44)   

vec_ft[el_to_ff]
vec_ft[c(11, 22, 33, 44)]
[1] 244 649 593 937
[1] 244 649 593 937

Wie wähle ich aus zweidimensionalen Daten aus?

Das wollte ich immer schon wissen!

Lass uns einen Datensatz erstellen

set.seed(123)
df_ft <- data.frame(
    id = 1:100,
    gen = sample(
        x = c("fem", "mal"),
        size = 100,
        replace = TRUE),
    age = sample(x = 19:31,
                size = 100,
                replace = TRUE),
    eg_cg = sample(
        x = c("eg", "cg"),
        size = 100,
        replace = TRUE),
    p_t01 = sample(
        x = 1:100,
        size = 100,
        replace = TRUE),
    p_t02 = sample(
        x = 1:100,
        size = 100,
        replace = TRUE)
)

Wie wähle ich nun aus Datensätzen aus?

  • Die Indizierung funktioniert wieder mittels [ ]
  • da data frames zweidimensional sind, müssen wir Zeilen und Spalten indizieren, daher [zeile, spalte]

Merke

Zeilen zuerst!

Wie sieht der Spass aus?

# Wähle den Wert in der 2. Zeile 
# und 4. Spalte aus
df_ft[2, 4]

# Wähle die Zeilen 80 bis 90 
# und die Spalte "age" aus
df_ft[80:90, "age"]

# Wähle Zeilen mithilfe eines 
# Objekts (el_to_ff) und die letzte Spalte aus
df_ft[el_to_ff, ncol(df_ft)]

# Wähle alle Teilnehmenden aus, 
# die in el_to_ff enthalten sind
df_ft[el_to_ff, ]
